# Next.js Cache Components Optimizer

This skill provides guidelines for optimizing existing cache implementations in Next.js.

## Optimization Strategies
- Minimize payload size for cached data.
- Utilize `revalidatePath` and `revalidateTag` for on-demand revalidation.
- Analyze cache hit rates and adjust time-based revalidation accordingly.
