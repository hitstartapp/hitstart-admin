# Next.js Cache Components Adoption

This skill provides guidelines for adopting Next.js cache components effectively.

## Guidelines
- Follow Next.js 15 documentation for the latest App Router caching strategies.
- Utilize `fetch` cache options, segment-level caching, and caching functions.
- Consider stale-while-revalidate (SWR) patterns when fetching data.
