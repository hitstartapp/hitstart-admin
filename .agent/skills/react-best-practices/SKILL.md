# React Best Practices

This skill outlines the standard best practices for React development.

## Core Principles
- Keep components small and focused on a single responsibility.
- Extract complex logic into custom hooks.
- Use memoization (`useMemo`, `useCallback`, `React.memo`) judiciously to prevent unnecessary renders.
- Manage state as close to where it's needed as possible.
